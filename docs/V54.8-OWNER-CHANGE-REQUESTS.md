# V54.8 — Owner Change Request Register (proposal-only)

## Delivered
- Durable SQLite `owner_change_requests` table with unique request IDs, bounded text fields, request category, timestamp and immutable `pending_review` state.
- `POST /api/v1/owner/change-requests` creates an Owner-authenticated proposal and appends a metadata-only audit event.
- `GET /api/v1/owner/change-requests?limit=50&offset=0` lists proposals (Owner only).
- Owner Master Console form and pending-proposal list.
- Five categories: customer account review, staff access review, configuration change review, KYC policy review, security incident review.
- Tests for persistence, validation, role denial and no-execution semantics.

## Strict limitations
- This registry is **not** an approval system. `pending_review` cannot be transitioned through this API.
- A proposal does not freeze/unfreeze accounts, decide KYC, change staff roles, rotate credentials, modify settings, enable trading or move funds.
- The shared Owner bearer-token model is not adequate to attest the identity of individual approvers; dual control needs a proper identity provider with phishing-resistant MFA, per-person credentials, separation of duties and tamper-evident signed decisions.
- Text fields are operational descriptions only. Do not enter government IDs, sensitive customer data, passwords, API keys or other secrets.
- The local SQLite file is suitable for development; production would require backed-up managed persistence, access policies, migration and retention controls.
- Neither successful CI nor this UI implies legal approval, licensed custody or readiness to accept customer deposits.

## Next stage prerequisites
1. External workforce identity provider and per-person MFA.
2. Independent reviewer and Owner decision roles, distinct principals and conflict-of-interest checks.
3. Immutable, append-only signed decision records and evidence retention.
4. Separate execution workers that require verified approval artifacts and policy gates.
5. Regulatory and security review before any live financial operations.
