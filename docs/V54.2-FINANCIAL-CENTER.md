# V54.2 — Financial Center

## Overview
Adds a role-protected, read-only financial summary to Owner Master Console.

## API
- `GET /api/v1/owner/finance/summary?days=30`
- Requires the existing `ledger` permission, so Owner, Finance and Compliance roles can request the report.
- `days` is constrained to 1–90.
- Uses a read-only SQLite connection and does not mutate accounting records.

## Metrics
- Simulated paper-trade count for the requested period.
- Paper-trade notional by quote asset, calculated as price × quantity.
- Simulated platform fee credits by asset, read from the `platform:fees` double-entry ledger account.
- Ledger transaction counts grouped by transaction kind.
- Daily volume and simulated fee summaries.

## Classification and limitations
All figures are explicitly classified as simulated paper trading. They are not real customer revenue, exchange fee receipts, bank balances, audited financial statements, proof of reserves, or custodied customer assets. The report does not convert different assets into a single fiat total because no trusted valuation source is supplied to this report.

The endpoint is read-only and does not support deposits, withdrawals, adjustments, payouts, or journal posting.

## Frontend
Owner Master Console now loads the 30-day financial summary and displays paper trade count, volume by quote asset, simulated fees by asset, and transaction counts by type. It clearly labels the report PAPER ONLY.

## Verification

- Route tests cover Finance-role authorization, unauthenticated access and invalid period rejection.
